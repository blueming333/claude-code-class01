# 广告日报页面 - 设计说明

## 功能需求

一个广告数据日报页面, 帮助广告投放人员快速了解当日投放效果。

### 核心指标
- 展示量、点击量、消耗、转化数 (今日汇总)
- 近7日消耗和转化趋势
- 各渠道的详细数据对比
- 自动生成的优化建议

### 交互
- 支持日期范围选择
- 点击刷新按钮重新生成数据

## 视觉设计

### 配色
- 主色: #6c5ce7 (紫色)
- 辅助色: #00b894 (绿色, 用于转化数)
- 背景: #f5f6fa (浅灰)
- 卡片: #ffffff (白色)
- 文字: #2d3436 (深灰)

### 布局
- 响应式网格布局
- KPI 卡片自动适配列数
- 表格支持横向滚动

### 字体
- 系统默认字体栈: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto

## 数据模型

```javascript
{
  date: string,           // YYYY-MM-DD
  channel: string,        // 渠道名称
  impressions: number,    // 展示量
  clicks: number,         // 点击量
  ctr: number,           // 点击率 (%)
  cost: number,          // 消耗 (元)
  conversions: number,   // 转化数
  conversionCost: number // 转化成本 (元)
}
```

## 优化建议规则

1. 消耗最高的渠道 → 建议重点关注转化效果
2. 点击率 < 1.5% 的渠道 → 建议优化创意素材或定向
3. 转化成本 > ¥100 的渠道 → 建议调整出价或优化落地页
4. 通用建议 → 确保数据口径一致
