# 广告日报页面 - 实现计划

## 概述

创建一个广告数据日报静态页面, 支持查看KPI指标、渠道明细和优化建议。

## 技术方案

- **纯前端**: HTML + CSS + JavaScript
- **图表库**: Chart.js (CDN)
- **数据**: 当前使用 Mock 数据, 后续可接入后端 API

## 文件结构

```
index.html  - 页面结构
style.css   - 样式
app.js      - 数据和交互逻辑
```

## 页面模块

### 1. KPI 卡片
- 展示量 (Impressions)
- 点击量 (Clicks)
- 消耗 (Cost)
- 转化数 (Conversions)

### 2. 趋势图
- 近7日消耗和转化数的双Y轴折线图

### 3. 渠道明细表
- 按渠道展示: 展示量、点击量、点击率、消耗、转化数、转化成本

### 4. 优化建议
- 基于当前数据自动生成优化建议
